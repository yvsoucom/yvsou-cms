# ⚙️ Domain View

Used to manage domain directories, group status, and content creation.

Key features include:

- Viewing all posts in the domain  
- Navigating subdomains  
- Managing group membership  
- Managing directory permissions and structure

For full controls, refer to [Root Domain Tool](#root-domain-tool).

# 📝 Post

Post management actions include:

- ✏️ Edit content  
- 📜 View revision history  
- 🌐 Change post language  
- 📂 Move or 📄 copy post to a group  
- 🔐 Manage post rights and 💬 comment permissions  
- ✅ Audit post for review  
- 🗑️ Move post to trash  
- ♻️ Recover post from trash  
- ❌ Permanently delete post

# 🛠️ Root Domain Tool

Provides access to root-level domain management, including group and content controls.

### Key Features

1. **View Domain Posts** – Display all posts in a directory  
2. **Create New Post** – Add new content in the domain  
3. **Group Status Overview**:
   - 👤 Joined – Number of current group members  
   - ⏳ Pending – Users waiting for group approval  
   - 🚫 Blocked – Users banned from the group  
4. **Join Domain Group** – Request membership in a domain group  
5. **Toggle Group Privacy** – Switch between public/private group access  
6. **Breadcrumb Navigation** – Shows directory path from root  
7. **Subdomain Listing** – View and manage nested subdirectories  
8. **Directory Management**:
   - Create new subdirectory  
   - Edit directory metadata  
   - Modify access rights  
9. **Group Management**:
   - Broadcast messages to group  
   - Send messages to specific users  
   - Approve or reject membership requests
