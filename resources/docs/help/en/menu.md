# 🏠 Home Page Sections

## 1. 🔍 Search Section

Allows users to search for posts and directories.

- a) Search keywords in posts → list matching posts.
- b) Search keywords in directories → list matching directories.
- c) Search user's posts → list matching posts.
- d) List all directories owned by the user.
- e) List all groups the user has joined.

## 2. 🌲 Domain Trees

A hierarchical tree view of all domain directories.

## 3. 🆕 New Posts

Displays a list of recently created posts.

### Post Actions
- ✏️ Edit
- 🔐 Show Rights

## 4. 📁 New Directories

Shows a list of newly created directories.

### Post View

# 🛠️ Root Domain Tool

Access and manage root-level domain directories.

### Domain View Features

1. **View domain posts** – list all posts in a domain.
2. **Create new post** – add content to a domain directory.
3. **Group Status Overview**:
   - 👤 Joined: number of users currently in the group
   - ⏳ Pending: number of users awaiting approval for private group access
   - 🚫 Blocked: number of users blocked from the group
4. **Join Domain Group** – become a member of the domain group.
5. **Toggle Group Privacy** – switch between public and private.
6. **Breadcrumb Navigation** – shows the path from root to the current directory.
7. **Sub Domains** – list all subdirectories in a domain.
8. **Directory Management**:
   - a) Create new sub-directory
   - b) Edit sub-directory
   - c) Edit access rights
9. **Group Management**:
   - a) Broadcast messages to the group
   - b) Send messages to specific users
   - c) Approve group membership requests
