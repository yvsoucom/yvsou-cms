# 私たちについて

**yvsou-cms** へようこそ！

**yvsou-cms** は強力なコンテンツ管理システム（CMS）です。特徴：
- きめ細かい権限管理
- 柔軟で動的なディレクトリ構造
- 拡張性と商用利用を前提とした設計

**yvsou-cms** で、コミュニティを構築し、コンテンツを安心して管理し、世界に向けてビジネスを拡大しましょう。
