# ⚙️ ドメインビュー

ドメインディレクトリ、グループステータス、コンテンツ作成の管理に使用します。

主な機能：

# 📝 投稿

投稿管理アクション：

- ✏️ コンテンツ編集  
- 📜 リビジョン履歴閲覧  
- 🌐 投稿の言語変更  
- 📂 グループへの移動または 📄 コピー

# 🛠️ ルートドメインツール

ルートレベルのドメイン管理、グループ管理、コンテンツ管理を提供。

### 主な機能

1. **ドメイン投稿の表示** – ディレクトリ内のすべての投稿表示  
2. **新規投稿の作成** – 現在のディレクトリに投稿を追加  
3. **グループステータス概要**：
   - 👤 参加済み – 現在のメンバー数  
   - ⏳ 保留中 – 承認待ちのユーザー数  
   - 🚫 ブロック済み – グループから禁止されたユーザー数  
4. **ドメイングループへの参加** – メンバーシップ申請  
5. **グループのプライバシー切り替え** – 公開/非公開の切り替え  
6. **パンくずリストナビゲーション** – ルートから現在のディレクトリへのパス表示  
7. **サブドメインリスト** – ネストされたサブディレクトリの表示・管理  
8. **ディレクトリ管理**：
   - 新規サブディレクトリの作成  
   - ディレクトリのメタデータ編集  
   - アクセス権の変更  
9. **グループ管理**：
   - グループへのメッセージ一斉送信  
   - 特定ユーザーへのメッセージ送信  
   - メンバーシップ申請の承認/拒否

# 📝 登録

1. 登録フォームの入力：
   - **名前**（一意であること）  
   - **メールアドレス**（一意であること）

   - 確認リンクが送信されます  
   - リンクをクリックしてアカウントを有効化
