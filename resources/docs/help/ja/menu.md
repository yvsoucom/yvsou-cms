# 🏠 ホームページセクション

## 1. 🔍 検索セクション

ユーザーは投稿やディレクトリを検索できます。

- a) 投稿をキーワードで検索 → 一致する投稿を表示。
- b) ディレクトリをキーワードで検索 → 一致するディレクトリを表示。
- c) 自分の投稿を検索 → 一致する投稿を表示。
- d) 自分が所有するすべてのディレクトリを表示。
- e) 自分が参加しているグループをすべて表示。

## 2. 🌲 ドメインツリー

すべてのドメインディレクトリを階層的に表示します。

## 3. 🆕 新着投稿

最近作成された投稿を一覧表示します。

### 投稿の操作
- ✏️ 編集
- 🔐 権限を表示
- 💬 コメント権限を表示
- 📂 グループに移動
- 📄 グループにコピー
- 🌐 言語を変更
- 📜 履歴を見る
- ✅ 審査チェック
- 🗑️ 削除

## 4. 📁 新しいディレクトリ

新しく作成されたディレクトリを一覧表示します。

### 投稿ビュー
- ドメイン内のすべての投稿を表示します。

# 🛠️ ルートドメインツール

ルートレベルのドメインディレクトリにアクセスし、管理します。

### ドメインビュー機能

1. **ドメイン投稿の表示** – 該当ドメインのすべての投稿を一覧表示。
2. **新しい投稿を作成** – 現在のディレクトリに投稿を追加。
3. **グループの状態の概要**：
   - 👤 参加中：グループに参加しているユーザー数
   - ⏳ 保留中：承認待ちのユーザー数（プライベートグループ）
   - 🚫 ブロック中：グループからブロックされているユーザー数
4. **ドメイングループに参加** – グループに参加します。
5. **グループの公開/非公開切り替え**
6. **パンくずナビゲーション** – ルートから現在のディレクトリまでのパスを表示。
7. **サブドメイン** – サブディレクトリの一覧。
8. **ディレクトリ管理**：
   - a) サブディレクトリの作成
   - b) サブディレクトリの編集
   - c) アクセス権限の編集
9. **グループ管理**：
   - a) グループ全体へのメッセージ送信
   - b) 個別のユーザーにメッセージ送信
   - c) グループ申請の承認

# 🔐 ログイン

1. アカウントにログインします。
2. パスワードを忘れた場合はリセットします。

# 📝 登録

1. 新しいアカウントを作成：
   - **名前**（一意である必要あり）
   - **メールアドレス**（一意である必要あり）
   - **パスワード**
2. **メール認証**：
   - 確認リンクがメールに送信されます。
   - リンクをクリックしてアカウントを有効化します。
