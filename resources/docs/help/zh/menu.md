# ⚙️ 域视图

# 📝 帖子

帖子管理操作包括：

- ✏️ 编辑内容  
- 📜 查看修订历史  
- 🌐 更改帖子语言  
- 📂 移动或 📄 复制帖子到群组  
- 🔐 管理帖子权限和 💬 评论权限  
- ✅ 审核帖子  
- 🗑️ 将帖子移至回收站  
- ♻️ 从回收站恢复帖子  
- ❌ 永久删除帖子

# 🛠️ 根域工具

提供根目录下的域管理、组控制及内容管理功能。

### 主要功能

1. **查看域帖子** – 显示目录中的所有帖子  
2. **新建帖子** – 在当前目录中添加内容  
3. **组状态概览**：
   - 👤 已加入 – 当前成员数  
   - ⏳ 待审批 – 等待批准的用户  
   - 🚫 被封禁 – 被禁止访问的用户  
4. **加入域群组** – 申请成为成员  
5. **切换群组隐私** – 公共或私有切换  
6. **面包屑导航** – 显示从根目录到当前位置的路径  
7. **子域列表** – 查看和管理嵌套子目录  
8. **目录管理**：
   - 创建新子目录  
   - 编辑目录信息  
   - 修改访问权限  
9. **群组管理**：
   - 向群组广播消息  
   - 向特定用户发送消息  
   - 批准或拒绝入群申请
