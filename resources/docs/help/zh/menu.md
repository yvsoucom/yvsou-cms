# 🏠 首页部分

## 1. 🔍 搜索区域

允许用户搜索帖子和目录。

- a) 根据关键字搜索帖子 → 显示匹配的帖子列表。
- b) 根据关键字搜索目录 → 显示匹配的目录列表。
- c) 搜索用户自己的帖子 → 显示匹配的帖子列表。
- d) 列出用户拥有的所有目录。
- e) 列出用户加入的所有群组。

## 2. 🌲 域树

## 3. 🆕 最新帖子

# 🛠️ 根域工具

访问并管理根级域目录。

### 域视图功能

1. **查看域帖子** – 列出该域下的所有帖子。
2. **创建新帖子** – 在当前域目录中添加内容。
3. **群组状态概览**：
   - 👤 已加入：当前加入群组的用户数量
   - ⏳ 待审批：申请加入私有群组的用户数量
   - 🚫 被屏蔽：被群组屏蔽的用户数量
4. **加入域群组** – 成为该域群组的成员。
5. **切换群组隐私** – 在公开和私有之间切换。
6. **面包屑导航** – 显示从根目录到当前目录的路径。
7. **子域** – 列出该域下的所有子目录。
8. **目录管理**：
   - a) 创建子目录
   - b) 编辑子目录
   - c) 编辑访问权限
9. **群组管理**：
   - a) 向群组发送广播消息
   - b) 向用户发送消息
   - c) 审核群组申请
